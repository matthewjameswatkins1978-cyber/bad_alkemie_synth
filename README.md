# Bad Alkemie Synth

**A separate home for an experimental standalone synthesizer.**

Bad Alkemie Synth is intended to be a synthesizer project in its own right, independent of the Bunny Deluxe / Pocket Drummer work. The idea is to give the instrument its own identity and room to develop rather than burying it inside a drummer's codebase.

## Where it stands

**Concept / repository scaffold.** There is no synthesizer implementation here yet, and nothing to build, install, or audition. At present the repository contains this introduction and a Git ignore file.

That distinction matters: this is a starting point, not a released instrument.

## Direction

The initial boundary is deliberately simple:

- **Synthesizer first.** Design and implementation belong here, not in the drum-machine repository.
- **Independent development.** The instrument should be able to evolve without requiring Bunny Deluxe.
- **Prove the sound.** When development begins, a minimal playable signal path should come before a mountain of interface or architecture.

No particular synthesis engine, plugin format, operating-system target, or release date has been committed to in this repository.

## Following the project

Check the repository history for subsequent experiments and source code. Once there is a working prototype, this README should gain a genuine audio example, build instructions, and an honest list of supported controls.
